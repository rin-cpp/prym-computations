# Magma computations for arithmetic Prym constructions

This repository contains Magma code accompanying the thesis

**Explicit Prym Constructions of (1,2)-Polarized Abelian Surfaces**

by Negarin Mohammadi.

The code implements computations involving:

- bitangents of smooth plane quartics;
- odd theta characteristics;
- Steiner systems and syzygetic configurations;
- labelling bitangents by theta characteristics;
- Galois actions on bitangents and two-torsion;
- the two-torsion associated with Prym varieties of bielliptic genus-3 curves.

The computations are used in the explicit examples appearing in the thesis (or future documents).
